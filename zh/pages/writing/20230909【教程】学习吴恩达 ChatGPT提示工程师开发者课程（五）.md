## 课程内容简介

### Inferring

这次的课程有大约12分钟，主要探讨了大型语言模型在文本推断方面的应用。首先，吴恩达教授强调了传统机器学习工作流中，对文本进行情感分析或其他类型分析所需的复杂步骤。但现在，通过大型语言模型，只需编写一个提示，即可迅速获得结果。这种方法不仅加速了应用开发，还减少了对多个模型的依赖，因为一个模型和API就能完成多种任务。

课程中展示了如何使用模型来判断文本的情感、提取文本中的特定信息，例如产品名称和制造商，以及如何从一段文本中提取主题。其中一个核心示例是基于产品评论的情感分析。通过简单的提示，模型可以判断评论是正面还是负面，并进一步提取评论中的具体情感和主题。

吴教授还提到了“零次学习算法”的概念，即不需要给模型任何带标签的训练数据，只需要一个提示，模型就能判断文本涉及的主题。他展示了如何使用这种方法来确定一篇文章涉及的特定主题，例如“NASA”或“联邦政府”。

最后，吴教授强调了在部署这些模型时需要注意的一些问题，特别是输出的一致性。**他建议在生产环境中，最好让模型以JSON格式输出答案，以增加健壮性**。

总体而言，这个课程展示了大型语言模型如何简化文本推断任务，使得原本需要数天或数周的工作现在只需要几分钟就可以完成。这为机器学习专家和新手都带来了巨大的便利。

```
def get_completion(prompt, model="gpt-3.5-turbo"):
    messages = [{"role": "user", "content": prompt}]
    response = openai.ChatCompletion.create(
        model=model,
        messages=messages,
        temperature=0, # this is the degree of randomness of the model's output
    )
    return response.choices[0].message["content"]
```
