> 下面给你一个简单的示例脚本，用于把指定目录下（按文件名排序）的所有图片从上到下拼接成一个长图。需要先安装 [Pillow](https://pillow.readthedocs.io/en/stable/)（pip install Pillow），示例代码如下：

```python
#!/usr/bin/env python3
# merge_long_image.py

import os
from PIL import Image

def merge_images_vertically(input_dir, output_file):
    """
    从指定目录按文件名顺序读取所有图片，并垂直拼接成一个长图。
    :param input_dir: 图片所在目录
    :param output_file: 输出的长图文件路径（含文件名）
    """
    # 1. 获取目录下所有图片文件，并按名称排序
    # 这里简单处理，只匹配了常见的几种后缀
    valid_ext = ('.jpg', '.jpeg', '.png', '.gif', '.bmp')
    image_files = [f for f in os.listdir(input_dir) if f.lower().endswith(valid_ext)]
    image_files.sort()  # 按文件名排序
    
    # 拼接完整路径
    image_paths = [os.path.join(input_dir, f) for f in image_files]
    
    # 如果没有图片，直接退出
    if not image_paths:
        print("目录中没有找到任何图片文件！")
        return

    # 2. 打开所有图片，并计算最终拼接图像的宽度和高度
    images = [Image.open(p) for p in image_paths]
    
    # 宽度：取所有图片的最大宽度
    max_width = max(img.width for img in images)
    # 高度：高度相加
    total_height = sum(img.height for img in images)

    # 3. 创建空白图像，用于拼接
    # 这里以RGB模式、白色背景为例
    merged_image = Image.new('RGB', (max_width, total_height), (255, 255, 255))

    # 4. 逐张图片粘贴到新图像上
    current_y = 0
    for img in images:
        # 如果想要居中，可以计算 x_offset
        # 例如：x_offset = (max_width - img.width) // 2
        # 这里简单地左对齐：
        x_offset = 0

        # 粘贴图片
        merged_image.paste(img, (x_offset, current_y))
        current_y += img.height

    # 5. 保存最终的长图
    merged_image.save(output_file)
    print(f"拼接完成，结果保存在：{output_file}")


if __name__ == "__main__":
    """
    示例：python merge_long_image.py <输入图片目录> <输出图片文件>
    """
    import sys
    if len(sys.argv) != 3:
        print("用法：python merge_long_image.py <图片目录> <输出文件>")
        sys.exit(1)

    input_dir = sys.argv[1]
    output_file = sys.argv[2]

    merge_images_vertically(input_dir, output_file)
```

> 使用说明：
>
> ​	1.	将上述脚本保存为 merge_long_image.py（或其他你喜欢的名字）。
>
> ​	2.	终端（或命令行）中执行：
>
> ``` python merge_long_image.py /path/to/images result.jpg```
>
> 参数：
>
> ​	•	/path/to/images：存放多张图片的目录。
>
> ​	•	result.jpg：输出长图的路径（含文件名）。
>
> ​	3.	程序会按文件名从小到大的顺序依次读取目录下的所有图片，然后从上到下拼成长图并输出到 result.jpg。
