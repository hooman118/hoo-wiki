# 【随笔】器材控的习性

大宝给阿宝报了一堂66元钱四次的乒乓球体验课，就在附近一个小区的地下室里。阿宝一开始还老大不愿意，在门口思想斗争了一会儿，终于跟着教练去玩了。

看她虽然有点紧张，但也跟着接球、捡球，半个小时玩下来，她竟然同意下次还要继续来上课。

其实，从看见她不亦乐乎地捡球开始，我就忍不住拿起手机开始搜寻乒乓球拍的选购说明了。之前大宝给她们买过一对儿杂牌的成品拍，轻薄地像纸板一样，那质感很像我小时候玩过的第一个光板球拍。我想，阿宝要是真的开始学习打乒乓球，不说她，我这个可能的潜在陪练就会想要一只更好的球拍。

再买一对儿小时候就用过的红双喜或者双鱼的成品拍？不！我的第一反应就是，成品拍还是性价比太低了。

于是乎，我翻着知乎、京东、拼多多、淘宝，一边反复阅读着几篇入门选乒乓球拍指南，一边仔仔细细对比着入门价位的红双喜、银河、729等球板、胶皮的说明和评价。

然后，一边在脑海里想象着应该买什么样的组合，一边琢磨着在哪个平台买性价比更高。

这个动作，并没有随着阿宝回到家而结束。

下午和晚上，我一次又一次地打开手机、打开电脑。

明明已经意识到，这其实是太过头的「器材控」症状表现，但我就是停不下来。

到了晚上11点，我心想，都刷了这么久了。如果就这么关掉，下次真要买时，不是又得重新来这么一趟么？

既然京东的直营店没有我想要的组合，但好歹京东上还有其他运动器材店，也算是依托京东这个平台，真假相对来说还是更能保障一些吧。

于是乎，我把自己想要的组合加入了购物车：

1. 银河U2的直板 / 横版 + 729-5 PRO + CJ8000
2. 银河U2的直板 / 横版 + 狂飙3 + 729-5 PRO 蓝海绵 

一个价格不到两百，一个价格不到三百，正在我大致上觉得心满意足地关上电脑、关上手机准备去睡觉时。我忽然想到，大约20多年前，我第一次用自己的工资给自己买的乒乓球拍，好像也是用的银河 + 狂飙 + 729 组合呀。

其实，像我这个水准的业余纯娱乐性三天打鱼爱好者，具体用什么器材，又能有多大区别呢？
