#【区块链】NoStr 怎么就火了

一开始，还只是加密货币圈的朋友们贴着那不知所谓的公钥，介绍着 Damus。昨天，忽然发现一个传统 IT 媒体的朋友竟然也在朋友圈贴出了自己的公钥，还 diss 那些询问这是什么东西的朋友落伍了，不算 IT人士🤣

简直太神奇了，我一直认为，公私钥这种一大串 16 进制数码，反人类直觉的账号体系，是普通人进入加密圈的最大障碍。总要等到哪些先行者找到切实办法，真正扫平它才行。但没想到，仅靠着马一龙和杰客多雷西这一正一反地宣传号召，就把 NoStr 带出圈了。

新鲜玩意儿带来的激情，把前几天的莫名悲哀情绪一扫而空。我也别落后了，找个客户端试试它吧…

这么想着，却发现自己果然还是晚了一步，Damus 的 Testflight 居然已经满员了。只好换用字符界面的 Nostr Console 试试，结果系统直接异常退出了…失去了程序员时代解决 bug 问题的耐心，我直接又试了试 web 版的 Astral.Ninja，倒是可以操作，但似乎特别地慢，啥内容也看不到。

又换成 iris.io 的 web 版，这个速度不错。看起来也就是一个简版的 Twitter。而且，和 Astral 的内容不互通…后来一想也正常，内容的互通靠的是中继服务器，这两家有延迟甚至隔离也都是正常的情况…

话说回到 nostr 本身，其实，这个协议的应用场景还是很值得期待的，有点 http 的感觉。如果 Telegram，mixin 这样的客户端也支持起这个协议，岂不是会非常有趣吗？

再结合 IPFS 的存储，以及数字货币的激励，而且，纯分布式的中继也可以满足内容控制的需求。这么一想，有趣的未来可期啊！

难怪火出圈呢。
