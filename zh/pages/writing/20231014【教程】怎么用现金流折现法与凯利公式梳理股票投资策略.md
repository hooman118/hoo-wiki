## 什么时候买，什么时候卖

我们有两个策略可用：

1. **定投——本质上是在对趋势有判断，但难以判断买卖时机时我们可以采用的策略。**
2. **低估时买，高估时卖出**——这需要对内在价值有进一步定量的分析依据。

那么怎么分析呢，我的建议是采用 巴菲特所推崇的「**自由现金流折现法**」。

### 一、什么是「**自由现金流折现法**」

#### 人话定义： **就是资产的价值等于所有的未来现金流经过折扣后的现值的总和**

用这种办法算出资产现在值多少钱，于是乎，低买高卖的原则就有了一根准绳。当前「价格」比这个「价值」便宜了就值得买，当前「价格」比这个「价值」贵了就可以卖。

#### 核心概念一：投资就是牺牲眼前的现金流出作为代价来期待未来的现金流入的行为

现金流折现模型（discounted cash flow model，DCF 模型）旨在通过将所有未来的现金流折成现值来求得资产内在价值（intrinsic value），在逻辑上无可挑剔，是一个完美的思维框架。

#### 核心概念二：为何折现（如何折现），因为要考虑投资机会成本，折扣率（discount factor）= 无风险收益率 + 风险溢价

1年左右的投资，可参考风险很小的**国债**收益率。长期投资，可参考**黄金**以及历史通货膨胀率。这其实也也能给我们一个对比——相比买国债和黄金，当下这个资产是否更值得买呢？

美国国债，目前的年化收益率是5%左右；

而通货膨胀的常用近似公式是：

**通货膨胀率＝M2增速-GDP增速**

与20年左右长周期的黄金历史收益相当，大约都是7%——这就是我们一会儿要用到的参数。

### 三、怎么根据估值确定买入、卖出时机

基本原则说起来非常简单，**低买、高卖**，但是低多少算低，高多少算高呢？我们先做一些拍脑袋的原则好了：

1. 公司在增长期初期，价格达到估值范围左右时买入
2. 价格达到估值范围 1 / 2 甚至以下时买入
3. 价格达到估值范围 2 倍 甚至以上时卖出
4. 公司在增长期末期，价格达到估值范围左右时卖出

## 买多少（仓位控制）

买多少这个问题，我们可以用到凯利公式。

### 什么是凯利公式

凯利公式可以表达为：***f*∗=*bp*−*q* /  *b***

其中：

- *f*∗ 是最优投资比例。
- *b* 是赔率（例如，如果赔率是4:1，那么 *b* 就是4）。
- *p* 是获胜的概率。
- *q* 是失败的概率，等于 *1−p*

John L. Kelly, Jr. 在1956年发表的一篇名为"A New Interpretation of Information Rate"的论文。Kelly当时是贝尔实验室的一名研究员，他的论文是关于通信理论的，特别是如何最大化长期的信息传输速率。尽管他的工作主要关注通信，但他的思想很快被赌博和金融领域所采纳。特别是，赌徒和投资者注意到，他们可以使用Kelly的方法来最大化其长期财富，而不是单单追求每次投资的最大化回报。

伊德·桑普森（Ed Thorp）是Kelly公式在金融领域的早期采用者之一。桑普森是数学家和赌徒，他在1960年代写了一本书，介绍了如何使用数学策略在二十一点中获得优势。后来，他将这些原则应用于股票市场和对冲基金，成为了一位非常成功的投资者。

凯利公式在赌博和投资界变得非常受欢迎的部分原因是，它减少了破产的概率（至少在理论上）。使用凯利公式，投资者不太可能把所有的钱都输光，因为它建议根据赔率和胜率来调整投注或投资的大小。

### 我们怎么用凯利公式控制投资仓位

因为股票很少会有赔光的情况，而且就算是「赢」，也不只有一种收益。所以，我们要稍微根据股票投资的情况，调整一下凯利公式：

***f*∗=*b1p1*+*b2/p2*+...+bn/pn /  *b~max~***

* bn 是每种情况下的收益
* pn 是每种情况发生的概率
* b~max~是最大收益

那么接下来，我们要对各种情况可能发生的概率做个拍脑袋估算，稍微简化一下。先假设之前估值正确的概率只有50%吧，高估1倍的概率也是50%；然后在之后的20年间，有2倍估值泡沫退出的机会是其中的80%，另外还有20%的机会只能按实际估值退出。

|          | 概率 |                 | 概率      | 收益 / 损失 |
| -------- | ---- | --------------- | --------- | ----------- |
| 估值正确 | 50%  | 2倍实际估值退出 | 50%* 80%  | 1           |
| 估值正确 | 50%  | 1倍实际估值退出 | 50% * 20% | 0           |
| 高估100% | 50%  | 2倍实际估值退出 | 50% * 80% | 0           |
| 高估100% | 50%  | 1倍实际估值退出 | 50% * 20% | -0.5        |

所以 *f*∗ =（ 1 * 50% * 80% + 0 * 50% * 20% + 0 * 50% * 80% - 0.5 * 50% * 20% ）/ 1 = （0.4 + 0 + 0 - 0.05 ） / 1 = 35%

也就是说，我们应该用35% 的仓位，以**US$ 449.61** 的价格买NVDA的股票。

话说，如果股票跌倒估值的1半价格该怎么办呢？这时候动手，实际上在买入时已经获得了一个很好的“折扣”。所以，会有更好的收益率：

1. 估值正确，2倍实际估值退出（实际回报是3，因为你买入时的价格是估值的50%，而退出时价格是2倍估值）： 预期回报=3×0.5×0.8=1.2预期回报=3×0.5×0.8=1.2
2. 估值正确，1倍实际估值退出（实际回报是2，因为你买入时的价格是估值的50%，退出时价格是估值）： 预期回报=2×0.5×0.2=0.2预期回报=2×0.5×0.2=0.2
3. 高估100%，2倍实际估值退出（实际回报是2，因为即使你的估值高了100%，但你买入时的价格是正确估值的50%，所以退出时你的回报是2倍买入价格）： 预期回报=2×0.5×0.8=0.8预期回报=2×0.5×0.8=0.8
4. 高估100%，1倍实际估值退出（实际回报是1，因为你买入时的价格是正确估值的50%，即使你高估了，退出时你的回报仍然是买入价格的2倍）： 预期回报=1×0.5×0.2=0.1预期回报=1×0.5×0.2=0.1

将这些预期回报加起来得到整体的预期回报： 总预期回报 = 1.2+0.2+0.8+0.1 = 2.3

考虑可能的最大回报。在最佳情况下，如果估值正确且以2倍实际估值退出，你的回报是3倍你的买入价格。所以，最大回报是3。

 *f*∗ = 2.3 / 3 = 76.67%

也就是说，如果真的跌了一半，我们应该用76.67% 的仓位，以大约**US$ 224.8** 的价格买NVDA的股票。

## 总结

1. 买什么（股票）？
2. 什么时候买，什么时候卖？
3. 买多少（仓位控制）？

关于这三个问题的答案如下：

1. **人工智能领域垄断了最多数据的那些基础设施公司，以及区块链领域Top5的数字资产**
2. 蛋壳法则定投 + 根据自由现金流折现法估值后低买高卖：
   * 公司在增长期初期，价格达到估值范围左右时买入
   * 价格达到估值范围 1 / 2 甚至以下时买入
   * 价格达到估值范围 2 倍 甚至以上时卖出
   * 公司在增长期末期，价格达到估值范围左右时卖出
3. 用调整后的凯利公式 ***f*∗=*b1p1*+*b2/p2*+...+bn/pn /  *b~max~*** 计算理论上的投资仓位



当然，在这价值估算和概率估算的过程中，有着许多假设，每一个假设都会对最终的结果有巨大的影响。并且同时，我们还要考虑我们实际的风险承受能力——比如中途出现巨额回撤（亏损）时，我们是否能坚持这投资策略呢？

睡得着吗？有融资吗？有紧急情况需要用钱不得不变卖投资资产吗？等等……
