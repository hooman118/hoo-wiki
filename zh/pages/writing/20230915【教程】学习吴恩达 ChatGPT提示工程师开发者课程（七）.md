## 课程内容简介

### Expanding

#### 1. 扩展的概念：

- 将较短的文本转化为较长的文本，如将指令转化为一篇文章。
- 使用大型语言模型作为创意伙伴的优势。
- 请负责任地使用模型，避免产生问题，如生成垃圾邮件。

#### 2. 生成个性化的电子邮件：

- 根据信息生成电子邮件的方法。
- 强调AI生成内容时的透明度的重要性。

#### 3. 使用“temperature”参数：

- “temperature”定义了模型响应的随机性和多样性。
- 在不同的“temperature”下，模型的输出会有所不同。
- “temperature”为零时，模型的输出是最可靠的；较高的“temperature”可能导致更随机的输出。

#### 4. 实际应用示例：

- 根据客户评论生成定制的电子邮件回复。
- 根据评论的情感定制回复内容。
- 强调AI生成的内容应该明确标注出处。

#### 5. “temperature”参数的深入应用：

- 对于相同的输入，不同的“temperature”会产生不同的输出。
- 温度为零时的输出与温度为0.7时的输出的差异示例。
- 建议使用者自行尝试不同的“temperature”来观察输出的变化。

#### 6. 结论和建议：

- 在需要可预测性的应用中，建议使用温度为零。
- 在寻求创意输出时，可以考虑使用更高的“temperature”。

def get_completion(prompt, model="gpt-3.5-turbo",temperature=0): # Andrew mentioned that the prompt/ completion paradigm is preferable for this class
    messages = [{"role": "user", "content": prompt}]
    response = openai.ChatCompletion.create(
        model=model,
        messages=messages,
        temperature=temperature, # this is the degree of randomness of the model's output
    )
    return response.choices[0].message["content"]
```
