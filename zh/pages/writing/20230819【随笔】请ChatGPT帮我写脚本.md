# 【随笔】请ChatGPT帮我写脚本

这两天，我在一个网站上查一些数据。发现有近400条信息，一条一条研究颇为费劲，于是乎，我想起找ChatGPT帮忙了。

一开始，我打开了一个GPT4的会话，Enable了几个Web Request 插件。然而，不管我怎么提示，它始终只能抓取网站的部分内容，分析的结果也不是那么让人满意。我心想，不如换条路线。先让它帮我写个脚本，把网站扒下来怎么样呢？

以前，我可是有很多次类似想法，但是没法操作——对于自己目前的写程序能力，不是那么有信心了。但是，如果是让GPT帮我写代码呢？果然，GPT二话不说，给我写了一段脚本，但是执行起来才发现——报错！

等我把错误信息告诉GPT，才发现这是非常简单的低级错误

——竟然是没有声明全局变量！

它一开始还一本正经地告诉我，这个错误是怎么回事，通常应该怎么修改，竟然还给了我另一段例子代码。这家伙的15秒金鱼脑，实在是让人哭笑不得。我不得不提醒它，这是执行它写的代码报的错。它才恍然大悟地抱歉，并开始修改自己之前的程序。如此折腾两次，才改完这个错误，但是运行后却没有得到想要的结果。GPT4再次给了我写了一小段代码，让我试着执行一下，然后把部分输出发给它看看。

我照做之后，它终于弄明白，原来这个网站是用JavaScript 动态加载数据的，于是建议我重新用Selenium写脚本，来模拟浏览器的行为。只不过，它说，用这个配置起来比较复杂，还需要安装驱动……

虽然它一再保证：

> 如果您在安装或使用过程中遇到任何问题，请告诉我，我会尽量帮助您解决。

我还是决定，明天再来尝试这个过程。不过呢，有一种感觉，有了ChatGPT这个小助手，有很多以前觉得难以完成的事情，似乎变得不再遥不可及了，起码我之前从来不知道Python有这些库可以完成这些任务。想想看，这还真是有意思！
