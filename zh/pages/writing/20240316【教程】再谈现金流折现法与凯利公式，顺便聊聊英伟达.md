### 什么是「**自由现金流折现法**」

简单来说，**就是把这家公司未来所有的现金流，按一定的折扣率，折算成现在的价值。**

![DALL·E 2024-03-16 22.24.38 - Create a wide-screen illustration that visually explains the concept of the Discounted Cash Flow (DCF) method. Excel和Google Sheet上都有现成的公式NPV 可用。

```
NPV(贴现率,现金流1, [现金流2, ...])
```

- `贴现率` - 一个期间内的投资贴现率。
- `现金流1` - 第一笔未来现金流。
- `现金流2, ...` - **[**可选**]** - 其他未来现金流。

我们需要做的，就是确定两个参数：

1. 折现率：我继续**使用7%，这是参考了黄金和美国国债**来的。要是不明白为什么，你们先照着用就好。
2. 现金流：那就参考NVDA的公开报表，继续拍脑袋。

### 接下来，仓位要怎么调整呢？继续用凯利公式算一下

根据股票投资的情况，调整过的凯利公式是这样的：

***f*∗=*b1p1*+*b2/p2*+...+bn/pn /  *b~max~***

* bn 是每种情况下的收益
* pn 是每种情况发生的概率
* b~max~是最大收益

我们再继续简化一下各种情况可能发生的概率（比如去年10月，估值就不太对嘛）。先假设之前估值正确的概率只有50%吧，高估1倍的概率也是50%；然后在之后的20年间，有2倍估值泡沫退出的机会是其中的80%，另外还有20%的机会只能按实际估值退出。按3.15的收盘价878.36美元计算收益 / 损失，我还是画张表：

|          | 概率 |                 | 概率      | 收益 / 损失                              |
| -------- | ---- | --------------- | --------- | ---------------------------------------- |
| 估值正确 | 50%  | 2倍实际估值退出 | 50%* 80%  | （2*1284.31 - 878.36 ）/ 878.36 = 1.92   |
| 估值正确 | 50%  | 1倍实际估值退出 | 50% * 20% | （1284.31 - 878.36）/ 878.36 = 0.46      |
| 高估100% | 50%  | 2倍实际估值退出 | 50% * 80% | （1284.31 - 878.36）/ 878.36 = 0.46      |
| 高估100% | 50%  | 1倍实际估值退出 | 50% * 20% | （1284.31 / 2 - 878.36）/ 878.36 = -0.27 |

所以，所以 *f*∗ = 1.92 * 50% * 80% + 0.46 * 50% * 20% + 0.46 * 50% * 80% - 0.27 * 50% * 20% = 0.768 + 0.046 + 0.184 - 0.027 = 97.1%

也就是说，按照3.15的收盘价，我们可以97.1%的仓位买入NVDA的股票（擦，这可是接近100%啊！！！为啥去年10月我没算出这个数来呢？）。
