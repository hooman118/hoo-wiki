## 课程内容简介

### Transforming

这堂课大约还是12分钟左右，吴恩达教授深入探讨了大型语言模型的强大功能，重点介绍了如何对输入内容进行多种格式的转换。这些模型不仅可以将文本从一种语言翻译成另一种语言，还可以帮助进行拼写和语法修正。特别是对于我个人来说，我也经常在做英语相关的工作时，把GPT当翻译用，所以这部分内容特别吸引了我的注意。吴教授用了很多生动的实例来展示这些功能，不仅仅是语言翻译，还可以格式转换，比如从Json到Html。

在课程中，我还学到了一些实用的技巧。例如，在提示中明确要求“Proofread and correct”可以更好地指导模型进行文本的校对和修正。这对于我之后的项目来说是非常有价值的建议。除此之外，课程里还介绍了一个名为Redline的Python包，这个工具可以方便地展示文本之间的差异。这种可视化比较的方法对于检查模型的修正效果或者比较不同版本的文档都非常有用。我认为这是一个值得进一步研究的工具。

课程的最后部分涉及了如何根据目标受众调整文本的语调。这部分内容对于需要针对不同受众写作的人来说非常有益。

翻译、文本修正、格式转换、调整文本的语调，吴教授和Isa用这些Transforming的例子，让我对大型模型在这方面的能力和边界有了更加深入的理解。

```
def get_completion(prompt, model="gpt-3.5-turbo", temperature=0): 
    messages = [{"role": "user", "content": prompt}]
    response = openai.ChatCompletion.create(
        model=model,
        messages=messages,
        temperature=temperature, 
    )
    return response.choices[0].message["content"]
```
