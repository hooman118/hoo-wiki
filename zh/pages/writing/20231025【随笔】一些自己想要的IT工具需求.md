# 【随笔】一些自己想要的IT工具需求

可能是自己的个性使然，日子过着过着，事情做着做着，就忍不住会想，如果有某某工具，这样这样，那样那样就好了。最近脑子里类似的想法转来转去，索性先记录下来，为将来做个参考吧。

1. 首先，还是觉得自己缺少一个趁手的写文章、发表的工具体系。理想情况是，能够在Mac 和移动平台沉浸式写作，支持Markdown，自动同步、备份，一键自动发布到个人网站以及微信公众号等自媒体平台。而我目前正在使用的工具套件显然是不完备的：

   * Mac 上写作：Typora + 双拼输入法很好地满足了我在Mac上写作的需求：支持Markdown，存储为文件
   * 手机上写作：无，在试用Obsidian，但不能和Typora存储的文件直接互动。写完后，需要在电脑上用Typora重新复制过去。
   * 文章存储：iCloud + Github。iCloud 的自动同步倒是很方便，但Github的同步，目前还需要敲命令，还没写成健壮的自动化脚步（由于iCloud节省存储的功能会删除本地文件，常常引发Github提交时的一些异常）
   * 文章配图：以前只在微信公众号搜索图片使用，现在发现GPT4 内置的DALL•E 3 已经足够好用了。
   * 文章发表：
     * Github ，用的Github提供的主页功能 + MDWiki，不过自动生成文章列表的程序还不够健壮好用，以至于一忙我很久都没更新Github主页目录了。
     * 微信公众号，发表时需要手工从Typora 拷贝粘贴到公众号的编辑后台。遇到图片还得一张一张上传，这个过程颇为耗时。而且，以前支持的格式（比如代码块）现在忽然不支持了，从Typora拷贝过去后会遇到格式丢失。这个烦心事儿真不好解决。

2. 与写作、乃至工作有关的个人的知识库、助理。以前特别留意这方面的工具，用过好几种工具，以存留在印象笔记的内容最多。现在用过ChatGPT 之后，深深感觉，应该构建一个和个人知识库积累联动的AI个人助理，这样能够在工作中无缝地调用自己可能用到的，过去积累的知识。

3. 我喜欢给孩子们读书、读故事。要是有一个音箱，能轻松地调用我朗读过、发表在荔枝或者喜马拉雅这些平台的故事，和孩子们互动就好了。最好还能和ChatGPT结合起来，以我的风格加上GPT的能力，随时给孩子们编故事更好。

4. 能够完美调用ChatGPT 这种大模型语言能力的翻译工具，有两个场景：

   * 文章、PDF、PPT这些工作、学习中用到的资料翻译
   * 日常生活中，实时的语音翻译——当然，最好是科幻片里巴别鱼的效果，但其实如果能把GPT现有的语言能力，和现实环境的语音输入输出有机结合起来，就能解决很大问题了。

   

所有这些想法，目前其实都有类似的实现，但都不够完美、不能满足我的个性化需求。因此，这又回到我的工作主业，有没有一系列覆盖软件工程整个系统流程的AI工具组，能把个性化实现我上面这些软件工具需求的门槛大幅降低呢？这样，让我这样的人，也能够低成本、快速地实现并验证自己的想法与需求？

于是，目前这样软件需求与供给的不匹配情况，会大大地被改善？
